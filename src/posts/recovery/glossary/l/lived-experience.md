# Commentary
If you're anything like me (which if you are, my condolences), you might have been tempted to dismiss these as "anecdotes" that don't count as real data, which we only get through quanitative measurements that are "objective" and reproducible. Personally, I feel short-sighted for having felt that way and ignoring how the intuition of lived experience is necessarily the starting point for any paradigm we might apply.
