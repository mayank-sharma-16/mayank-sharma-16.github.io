# Overview
Cannabis refers to a psychoactive substance derived from Cannabis plants, which contains more than 100 compounds called [[cannabinoids|cannabinoids]] that interact with the body's [[endocannabinoids|endocannabinoid]] system. It can be consumed through smoking, vaping, edibles, pills, tablets, and lotions to produce feelings of [[euphoria|euphoria]] and relaxation. The main component responsible for the "high" is tetrahydrocannabinol (THC), while cannabidiol (CBD) doesn't cause a "high" while still having therapeutic properties.
