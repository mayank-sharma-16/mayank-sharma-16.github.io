# Overview
The North American Syringe Exchange Network (NASEN) maintains a searchable directory of [[syringe-services-program|syringe services programs (SSPs)]] and other [[harm-reduction|harm-reduction]] services. It relies on self-reporting, so programs aren't listed until they reach out to the directory for inclusion.
