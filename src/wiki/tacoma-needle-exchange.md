# Overview
The Tacoma Needle Exchange is run by the [[dave-purchase-project|Dave Purchase Project]] and operates as a [[syringe-services-program|syringe service program (SSP)]] that provides clean instruments in return for dirty ones as part of a [[harm-reduction|harm-reduction]] approach to reducing [[overdose|overdoses]].
