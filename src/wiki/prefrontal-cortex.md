# Overview
The prefrontal cortex is part of the brain's frontal lobe and plays a central role in complex behavior and higher-order thinking.

## Key Functions

- Executive Function

- Impulse Control

- Self-Regulation

- Working Memory

- Social Cognition

## Subregions

- Dorsolateral Prefrontal Cortex (dlPFC)

- Ventromedial Prefrontal Cortex (vmPFC)
