# Overview
Naltrexone is an [[opioid|opioid]] [[antagonist|antagonist]] that reduces cravings and blocks feelings of [[euphoria|euphoria]] for both Alcohol Use Disorder (AUD) and [[opioid-use-disorder|Opioid Use Disorder (OUD)]]. It can be taken as a monthly injection called [[vivitrol|Vivitrol]].
