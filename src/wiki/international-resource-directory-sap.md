# Overview
The International Resource Directory is maintained by the [[society-of-addiction-psychology|Society of Addiction Psychology (SAP)]], which is a division of the [[american-psychological-association|American Psychological Association (APA)]]. It includes [[substance-use-disorder|Substance Use Disorder (SUD)]] research, clinical guidelines, and educational materials.
