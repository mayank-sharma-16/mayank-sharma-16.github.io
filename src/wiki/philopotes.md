# Overview
Philopotes is an ancient Greek term that translates literally to "lover of drinking." It didn't have a negative connotation the way we might associate with "drunk" or "heavy drinker"; "partygoer" is a more fair comparison, since it might have been used to describe someone attending a party called a symposia. In some ancient Greek theater, a philopotes might have referred to an archetypal character whose drinking provides comic relief.
