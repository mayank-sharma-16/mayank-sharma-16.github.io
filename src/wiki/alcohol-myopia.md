# Overview
The Alcohol Myopia Model (AMM) is a theory about the way substance use influences decision-making processes. In the same way that myopia (nearsightedness) represents a limitation around one's perspective, AMM describes a limitation on the brain's processing capacity to weigh the trade-offs around decisions or control reactive impulses. If intoxication impairs attention, someone might only be able to engage with the immediate cues in some activity front of them, which could boost self-esteem and block negative self-evaluations. At the same time, intoxication would interfere with long-term planning and short-term inhibitions, which can lead someone to act with much more impulsive confidence.
