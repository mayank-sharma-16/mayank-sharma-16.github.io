# Overview
Medication for Opioid Use Disorder (MOUD) involves the use of medications that alleviate the cravings of [[opioid-use-disorder|Opioid Use Disorder (OUD)]] without providing the same [[euphoria|euphoria]] as actual [[opioid|opioids]]. The biggest examples include [[buprenorphine|buprenorphine]], [[methadone|methadone]], and [[naltrexone|naltrexone]].
