# Overview
The State Unintentional Drug Overdose Reporting System (SUDORS) is a public health system designed to track overdoses, run by the Centers for Disease Control and Prevention (CDC) as part of the Overdose Data to Action (OD2A) program. It collects information on deaths caused by drug poisoning or [[overdose|overdose]], such as demographics, substances involved, delivery method, place of death, death scene investigation reports, and a medical history that includes prior overdoses. Some states run their own surveillance extensions, like the California State Unintentional Drug Overdose Reporting System (CA SUDORS) managed by the California Department of Public Health.
