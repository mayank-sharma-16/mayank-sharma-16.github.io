# Overview
The externalizing spectrumi is a psychological framework that groups impulsive and rule-breaking behaviors together because of shared predispositions in vulnerabilities and deficiencies in impulse control. This includes:

- [[attention-deficit-hyperactivity-disorder|Attention-Deficit Hyperactivity Disorder (ADHD)]]

- Oppositional Defiant Disorder (ODD)

- Conduct Disorder (CD)

- Antisocial Personality Disorder (ASPD)

- Substance use disorder (SUD)

Researchers have found that common sub-factors like "disruptive-dissocial" and "impulsive-hostile" can be found as part of the externalizing spectrum's dimensions. The Externalizing Spectrum Inventory (ESI) is a psychological assessment based on self-reporting traits tied to callous-aggression, substance use, and lack of inhibition.
