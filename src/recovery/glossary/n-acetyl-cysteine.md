# Overview
N-acetyl cysteine (NAC) is an amino acid supplement that can help raise antioxidants, decongest the lungs, and address acetaminophen overdoses. There is some mixed evidence on whether NAC can also address symptoms of Obsessive-Compulsive Disorder (OCD).
